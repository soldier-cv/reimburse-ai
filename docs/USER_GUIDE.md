# 使用指南

这是个人对公应收与报销管理台的使用说明。走通一次完整流程是：上传票据 → 在收件箱核对并确认入账 → 按公司归集为批次 → 提交给公司 → 记录到账 → 需要时导出财务包。

## 1. 产品口径

- **应收事项是唯一的账本事实。** 发票、截图、聊天记录、付款回单只是附件，用来证明这笔钱。
- 一笔应收只属于一个批次；批次是你向某一家公司的一次提交。
- **支持部分到账**：一笔应收可以被多笔到账分次核销。每笔到账必须分摊到具体应收，分摊合计必须等于到账金额，单笔分摊不能超过该应收的待收余额。
- 状态依次是：待提交 →（归集并提交）→ 已提交 → 部分到账 → 已到账。被驳回的可以退回待提交；已放弃是终态。
- 逾期不是单独存的状态，由「今天晚于预计到账日，且尚未结清」实时计算。
- 待收 = 应收金额 − 已收金额 − 核销差额（工资代扣等确认不再追收的部分）。草稿、被驳回、已放弃不计入待收。
- 工资与报销共用同一套应收模型，用类型区分报销、薪资和其他。
- 金额在系统内以「分」存储，界面和导出显示为元。

## 2. 采集与收件箱

收件箱页面的上传区域支持拖入、粘贴和点击选择文件，这是唯一的上传入口；在其他页面也可以直接把文件拖进页面或粘贴。文件会进入收件箱，不会直接记到台账。支持图片、PDF、OFD 和 ZIP；单文件不超过 25MB，一次最多 30 个文件。

压缩包会按其中的每个文件生成草稿。嵌套的压缩包和不支持的格式会明确告诉你跳过了哪些、为什么，而不会悄悄丢掉。通行费汇总单会把行程明细和原始发票包自动挂到主票据上。

上传后可以立刻看到：生成了几条草稿、跳过了几个、是否有疑似重复。识别在后台进行，金额必须你自己核对，模型没给出金额时不会用猜测值顶替。

收件箱可以按状态筛选（全部 / 待确认 / 识别失败 / 排队中 / 识别中），把「识别失败」单独筛出来重跑很方便。勾选草稿后会出现批量操作条：批量应用公司、批量应用归属月、批量重新识别、批量丢弃。「丢弃」只删除这份草稿和识别信息，**不会删除台账里已经确认入账的应收**；想清掉那笔应收要去台账单独删除。

金额为空或没选公司时不能确认入账。确认前会弹出汇总：笔数、金额、公司、归属月，以及还缺金额或公司的草稿。按公司分组时，一次确认只处理同一家公司的草稿。

赶时间的话，勾选草稿后点「一键入账并建批次」：把所选草稿确认成应收，随即按同一归属月建一个批次并提交给公司，不用再走台账勾选 → 归集 → 提交的几步。要求所选草稿归属月一致、公司和金额都已补全；检测到重复票据会先提示，确认后才继续。

「追加到已有应收」只从应收详情发起：把收件箱里的草稿挂到已有事项上，不改原金额。

出差时用手机打开收件箱，点「拍照上传」可以调用后置摄像头，拍完直接进入收件箱；桌面端不显示这个按钮，直接选择文件即可。

## 3. 归属月与发生日期

发生日期是票据上的日期（开票日、消费日或发薪日）。归属月是这笔钱记到哪一个月，可以与发生日期不在同一个月。例如 10 月 31 日的发票要报到 11 月，就把归属月改成 11 月，不必改发生日。

收件箱里每张草稿都有归属月，默认按发生日期带出，确认入账时可以改。按公司批量确认时，也可以一次给整组指定同一个归属月。

台账展示和筛选使用你确认过的归属月。已提交之后，归属月与金额、事项、公司、类别一起锁定。批次的归属月由所选应收汇总，且必须一致，不一致时不能归入同一批次。

看板和导出都使用确认后的归属月，而不是临时从发生日再推一次。

## 4. 应收台账与批次

只有「待提交」和「被驳回」的应收可以勾选归集，其他状态会禁用并说明原因。列表可以看到归属月和创建日期。手工录入一笔应收（例如补发、年终奖）也在台账的操作区，点「新增应收」。

搞错的单笔待提交/被驳回应收可以直接「删除」（软删、留审计）。如果一次录错多笔，勾选后点「批量删除」可一次清掉；已提交或已有到账的会自动跳过，不会被误删。

勾选后点「归集批次」进入三步流程：确认应收 → 填写提交日期与预计到账日 → 最后确认。「上一步」可以随时返回修改，取消则什么都不创建；只有最后一步点「创建并提交」才真正落库，因此不会留下半截批次。材料不全的应收会在第二步提示，需要勾选确认后才能继续。

合并 PDF、财务包和原件包在台账页勾选应收后可直接导出，也可以到导出中心按筛选条件导出，或从批次详情按批次导出。

批次页顶部可按状态、公司、归属年、归属月、逾期和关键词筛选；批次卡片把归属月和报销/工资类型单独显示，不用再从长标题里找。

已提交后，金额、事项、公司、类别和归属月被锁定。若要修改，先对批次「撤回提交」（必须填写原因，会写入审计），批次回到草稿后再调整。已到账或部分到账的批次不能撤回、不能拆，以免破坏已经核销的记录。

撤回提交后的草稿批次可以移出单笔、添加其他应收，或取消拆解（批次取消，应收退回待提交）。已提交但尚未到账的批次也可以取消，效果是拆掉批次并把应收退回待提交；日常更建议先撤回提交再调整。

已提交的应收不能删除，只能放弃并留下审计。放弃已提交的记录时必须填写原因。

### 批次到账

在批次列表或详情里「记录到账」时，需要选择到账日期；不选则默认为当天（按上海时区的本地日期）。可以填写备注，默认是「批次到账」。默认「整批到账」会把批次内尚未结清的**报销类**应收一次性按余额核销；如果只到了一部分钱，切到「部分到账」，勾选实际到账的应收并填各自的核销金额（合计须等于到账金额），其余保持未结清。批次里如果还有工资应收，会跳过并提示到对应工资上「登记实发」，因为工资的应收金额是税前、到账是实发，不能按余额记收款。

## 5. 薪资计划与到账核销

在「薪资计划」中为某家公司配置**税前月薪（应发）**、发薪日、生效日期和停发日期。发薪日按「次月 x 号」理解：填 15 表示 1 月的工资在 2 月 15 日发，所以 1 月归属月的工资应收，发生日和预计到账日都是 2 月 15 日（遇月末天数不足则取当月最后一天）。打开应用时会自动补齐缺失月份的工资应收；设置里也可以手动点「补齐缺失月份」。工资由计划生成后**默认就是已提交**，不需要再归集批次，直接等待发薪登记；同一家公司的同一个归属月不会重复生成。

计划生成的工资在台账里显示为「**待发薪**」（底层状态仍是已提交），它们**不进提交批次**——批次是报销款的提交，工资本身由计划生成、视为已提交，发薪后单独登记实发即可。

工资应收挂的是税前金额，因为计划里只有应发、没有每月实发。发薪后在「记录到账」里填**到账金额（实发）**，再勾选对应月份的工资：程序会按到账金额分摊，并勾选「按实发结清」，差额自动记为**代扣**，待收归零。所以一笔工资结清后是「应收 ¥20,000、实发 ¥15,000、代扣 ¥5,000、待收 ¥0」，四个数能对上。注意分摊栏填的是**实发数**（与到账金额一致），不是税前应发；填了到账金额再勾工资会自动按到账金额分摊，不必手改。

如果公司分几次发（例如先发一半），取消勾选「按实发结清」就按普通部分到账处理，剩下的继续挂在待收里，下次再结。

修改计划里的税前月薪不会重复生成同一月份的工资，也不会改动已到账的记录。计划生成的工资默认已提交；编辑时勾选「同步更新未发薪的工资应收」，可把该计划生成、尚未发薪且未归集的月份一起改成新金额，已到账的保持不动。

涨薪：结束旧计划（填写停发日期），再新建一份新金额、新生效日的计划。补发和年终奖不强制自动生成，可以直接在台账里手工录入，计划不会挡住这些操作。试用期可以先建一份较短区间的计划，转正后再建新计划。离职时填写停发日期或停用计划，之后不再生成。

工资到账截图仍按备注月份、最早欠发顺序和金额规则核销已有工资应收，不会新建应收。由计划生成的月份可以被这些规则匹配到；匹配时优先用历史实发金额做参考，不再要求到账金额等于税前金额。

草稿的**归属月会自动推断**：备注写明「2026年1月工资」就默认设为 2026-01；没写月份时，按待结清工资的最早欠发月推断。你手动改过的归属月不会被重新识别覆盖。银行转账附言里的多条费用明细也会各自推断归属月。

附言拆单的核销方案可以逐条编辑：改费用项、归属月、目标应收和金额，也能增删明细行。下拉里已被其它明细占用的应收会标注，界面会实时提示「有重复应收」或「分摊合计与到账金额不一致」，改到一致后才能核销。

### 银行转账附言拆单核销

公司把多笔报销款合成一笔银行转账打过来、附言里逐项列明金额时（例如「通行费：2月512.30、3月876.5、4月801.20」），上传这张转账详情截图即可。AI 会拆出每条明细的费用项、归属月和金额，草稿详情里显示「附言拆单核销」的方案：每笔明细匹配到**同公司、同归属月、同费用类别且已提交或部分到账**的应收，点「编辑」可以改目标应收和金额，把握度低的会标出问号提醒对照原图。

点「核销到账」后生成一笔到账记录，按明细分摊到这些应收上，每笔应收都挂一份这张截图作为到账凭证，按任意一笔导出财务包都带得上。

如果某条明细找不到对应的已提交应收，或者金额超过该应收的待收余额，**整笔都不会核销**，草稿里会列出具体原因。需要先在台账里把对应月份的事项建好并归集提交，或改用「登记到账」手工处理。待提交的应收不能作为拆单目标。

## 6. 导出中心

- 按筛选条件导出明细 Excel。
- 按勾选的应收或按批次合并票据 PDF。
- 导出财务包 ZIP：封面、Excel、合并 PDF、原件和截图；每次会留下导出记录和文件哈希。
- 也可以按应收、批次或归属月打包原始文件，方便交给 Agent 或自己归档，而不必附带封面和 Excel。

## 7. 成员与账本隔离

成员就是独立账本。管理员可以创建账号、重置密码、停用或删除成员，但不能查看成员账本里的应收、批次或附件。

默认只创建普通成员。若要创建管理员，需要在界面上做一次明确的二次确认。

停用后无法登录，数据保留，已有登录会话立即失效。删除是软删除：账号不能再登录，账本数据仍留在数据库里，该成员自己的上传文件会被清理，不会误删其他人的文件。

## 8. Agent 令牌与权限

在「设置 → Agent 令牌」为自己签发令牌。明文只在签发或重新签发时出现一次，关闭后无法再查看。库中只保存哈希。

重新签发会使旧令牌立即失效，新的明文同样只显示一次。令牌可以设置过期时间和最小权限范围：采集、台账、导出。

Agent 可以完成取件、识别、建账、归集、提交和导出，也可以读取 AI 是否启用以及模型名称，但看不到密钥。Agent 不能管理账号、不能签发或吊销令牌、不能改 AI 密钥、不能初始化管理员。所有写操作都会留下审计。

## 9. 在线预览

点击缩略图会在应用内打开预览，不必把整个文件下载下来再离开当前页面。图片和 PDF 都可以放大、拖动；PDF 可以左右翻页。需要原件时再点下载。

OFD 暂不支持在线预览，预览时会说明并提供下载入口。列表里的缩略图是小图，不会把原图直接送到列表。

## 10. 常见问题与已知边界

- **同一张票传了两次？** 相同文件或相同发票代码 + 发票号会在上传和确认时提示。你可以仍确认入账，但必须先看到风险。
- **公司怎么选？** 只有一家公司时会默认选中；有多家时按最近使用排列。
- **「今天」是哪一天？** 所有默认日期都按上海时区的本地日期，不会因为浏览器用 UTC 而在晚上变成昨天。
- 单币种人民币，不做汇率。
- 不做退款/红冲、预算、账户余额，也不做邮件或微信提醒。
- 不做发票税务验真。
- OFD 只保存原件，不自动识别，也不能在线预览。
- AI 需要你自行配置兼容 OpenAI 的接口；未配置时请手动填写金额。
